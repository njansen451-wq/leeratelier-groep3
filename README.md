# Leeratelier · groep3 (v0.14.5)

Deze map is gebouwd uit de bronrepo `natalia-learning-lab` met `node src/build.js --space groep3 dist/leeratelier-groep3`. Niet met de hand wijzigen: pas de bron aan en bouw opnieuw.

- Adres: https://leeratelier-groep3.nataliajansen.nl
- Opslag in de browser onder `philearn-groep3-…`
- Login: één gedeelde gebruikersnaam en één wachtwoord (de hash komt bij het bouwen uit `.env.local` in de bronrepo). Dit is een drempel tegen toevallige bezoekers, geen beveiliging.

Zie de README van de bronrepo voor bouwen, login en testen.
